Sobre o LisoFlix

O que é o LisoFlix?

O LisoFlix é um projeto de site voltado para a apresentação e organização de filmes e séries de diferentes gêneros.

O LisoFlix é uma plataforma de streaming real?

Não. O site foi desenvolvido como projeto acadêmico para a disciplina de Introdução à Programação Web.
