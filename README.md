# LisoFLix

O LisoFLix é um projeto acadêmico desenvolvido para a disciplina de Programação Web. A ideia é criar uma plataforma de apresentação de filmes e séries, com uma interface inspirada em serviços de streaming.

O site permite navegar pelo catálogo, pesquisar títulos, consultar informações sobre filmes e séries e conhecer diferentes opções de planos.

## Sobre o projeto

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com foco na organização das páginas, na aparência visual e na interação com o usuário.

## Funcionalidades

- Página inicial com apresentação do LisoFLix.
- Catálogo com filmes e séries.
- Pesquisa de títulos pelo nome.
- Página de detalhes com informações de cada título.
- Função "Minha Lista", que permite adicionar e remover títulos.
- Armazenamento da lista no navegador usando LocalStorage.
- Página de planos com comparação de benefícios.
- Página de suporte com formulário de contato que prepara uma mensagem para envio pelo WhatsApp.

## Páginas do site

| Página | Descrição |
|---|---|
| Início | Apresentação da plataforma e atalhos para outras páginas. |
| Catálogo | Exibe os filmes e séries disponíveis. |
| Detalhes | Apresenta sinopse, elenco, gênero e outras informações dos títulos. |
| Planos | Mostra as opções de planos e uma tabela comparativa. |
| Suporte | Disponibiliza um formulário para contato. |

## Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** estilos, cores, organização dos elementos e responsividade.
- **JavaScript:** funcionalidades e interações do site.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para executar o site e visualizar as alterações durante o desenvolvimento.

## Observações

O LisoFLix é um projeto acadêmico e não oferece um serviço real de streaming. Os planos, preços e benefícios apresentados são apenas ilustrativos.

A lista de títulos é armazenada localmente no navegador. O formulário de suporte prepara uma mensagem para o WhatsApp, mas não representa um sistema real de atendimento.
